# Weather Icons

The SVGs in `svg/` are from **Weather Icons 2.0.10** by Erik Flowers
(http://erikflowers.github.io/weather-icons — erik@helloerik.com), pruned to the icons
`Client.React/src/utils/weather.ts` maps to. Add a file back from the upstream set only together
with the mapping that uses it (`weather.test.ts` enforces this).
